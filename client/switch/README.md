# Client Nintendo Switch (homebrew)

1. Console com **Atmosphere** (CFW / desbloqueado).
2. Copie o conteúdo de `../linux/` + este `wyd748.nro` para `sdmc:/switch/wyd748/`.
3. Remova do SD os binários Linux (`project`, `WYD Arm64`, `libdxvk_*`, `dxvk-aarch64/`) se quiser.
4. Ajuste `serverlist.bin` para o IP do PC/VPS onde o servidor escuta (porta 8281).
5. Abra pelo Homebrew Menu.

O Switch **não** roda o servidor — só o client.
